# 💧 Purificadora Las Peques

PWA (Progressive Web App) para la gestión integral de una purificadora de agua: clientes, pedidos, cobranza, rutas y reportes.

## ✨ Características principales

- 📊 **Dashboard** con métricas clave del negocio
- 👥 **Clientes** — alta, edición y seguimiento
- 📦 **Pedidos** — gestión de órdenes de garrafones
- 💵 **Cobranza** — control de pagos y saldos
- 🗺️ **Rutas** — organización de reparto
- 📈 **Reportes** — exportación a Excel y PDF
- ⚙️ **Funciona sin internet** (modo offline / PWA)

## 🛠️ Stack técnico

- HTML5 + CSS3 + JavaScript (ES Modules)
- [SheetJS (xlsx)](https://sheetjs.com/) — exportación a Excel
- [jsPDF](https://github.com/parallax/jsPDF) — generación de PDF
- Service Worker para cacheo offline
- Web App Manifest para instalación en celular/escritorio

## 🚀 Instalación como App

Al abrir el sitio en Chrome (Android) o Edge/Chrome (escritorio), aparece la opción **"Instalar"**, quedando como una app nativa en el dispositivo.
